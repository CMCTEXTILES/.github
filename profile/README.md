## 🛡️ ENGINEERING & CONTRIBUTION PRINCIPLES

We aim to maintain repositories with clear ownership, traceable changes and responsible release practices.

1. **📖 Document first** — read the repository README, setup instructions, contribution guide and license.
2. **🌿 Branch for changes** — use a feature branch instead of committing directly to protected branches.
3. **🧪 Validate before merging** — provide relevant tests, checks or validation evidence.
4. **🔐 Protect sensitive information** — never commit credentials, API keys, customer records or production data.
5. **✅ Review before release** — production changes require the appropriate review and approval.
6. **⚖️ Respect upstream licenses** — retain copyright notices, license files and third-party attribution.

Access to private repositories is managed by the organization. Unless a repository explicitly states otherwise, treat its code and documentation as internal company material.
